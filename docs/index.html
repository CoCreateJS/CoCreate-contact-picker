CoCreate Contact Picker

Open the browser's contact picker with the getContacts action or the JavaScript API.

<button actions="getContacts">Choose contacts</button>

Selected contacts are stored on the action element as element.contacts and can be read with getValue() or getContacts(). The component renders the selected array through CoCreate Render and emits contactsSelected. The getContacts action completion also includes the array in event.detail.contacts.

Open the browser contact picker after the user clicks the button.
